# Agent instructions

## Keep the README in sync

Whenever a userscript is added to `src/`, or a script's `@name` (title) or `@description` changes, update the **Scripts** table in `README.md`:

- **Script** column: the script's `@name` value.
- **Description** column: a short summary of what the script does.
- **Install** column: `[Install](https://github.com/glenncarr/userscripts/raw/refs/heads/main/src/<file-name>.user.js)`.

Keep the table rows sorted alphabetically by script name, and remove rows for scripts that are deleted.
